# purchases-analysis-2022

Analysis of a company's 2022 purchase records (16,383 rows, 18 columns)
using Python, Pandas and Matplotlib.

Questions answered:
1. Which suppliers received the most purchase value? (...)
2. Which month had the highest purchases? (...)
3. Which products were bought in the highest quantity? (...)

Charts: see the .png files in this repository.

Note: The original dataset is not included in this repository.
Currency is not specified in the dataset.

Tools: Python, Pandas (groupby, datetime), Matplotlib, read_excel
